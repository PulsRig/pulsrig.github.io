HINWEIS ZUR WINDOWS-WARNUNG

PulsRig ist noch nicht digital signiert

Ein Zertifikat für die Signatur kostet mehrere hundert Euro im Jahr. Solange PulsRig keins hat, zeigt Windows beim ersten Start die Meldung „Der Computer wurde durch Windows geschützt“. Manche Virenscanner melden unsignierte Programme außerdem vorsichtshalber. Der Quellcode ist offen, du kannst jede Zeile auf GitHub nachlesen.

  1. In der blauen Meldung auf Weitere Informationen klicken.
  2. Prüfen, dass der Dateiname mit PulsRig beginnt.
  3. Auf Trotzdem ausführen klicken.
